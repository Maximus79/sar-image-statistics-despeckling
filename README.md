# SAR Image Statistics & Despeckling (IMA207)

> **Note:** this is a guided lab exercise completed as coursework at Télécom Paris / Institut Polytechnique de Paris — the notebook scaffolding (introduction, some helper code) was provided by the course instructors, and the derivations, analysis, and completed implementation are the author's own work.

Guided lab exercise (Télécom Paris, IMA207 — remote sensing) on the statistics of Synthetic Aperture Radar (SAR) imagery: empirically verifying the theoretical distributions of single-look SAR intensity and phase data, then implementing and evaluating despeckling (speckle noise reduction) methods.

**Course instructors:** Emanuele Dalsasso, Florence Tupin, Cristiano Ulondu Mendes, Thomas Bultingaire

**Stack:** Python, NumPy, SAR/remote sensing image processing
